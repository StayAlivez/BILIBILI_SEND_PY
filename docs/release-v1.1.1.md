## BILIBILI_SEND_PY v1.1.1

隐私补强版。

### 变更

- 日志与「检测直播间」只显示账号昵称，不再输出 UID（`DedeUserID`）
- README 补充隐私说明，截图更新为打码状态
- 与 v1.1.0 相同的隐私能力：Cookie 默认打码、「显示 Cookie」开关、「保存 Cookie」开关
- 免安装包仍内置 Python 3.11.9 + tkinter

### 使用

下载 `BILIBILI_SEND_PY_v1.1.1_portable_win64.zip`，解压后双击 `run.bat`；
如果没反应，双击 `debug.bat` 可以看到具体报错。
