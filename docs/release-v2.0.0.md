## BILIBILI_SEND_PY v2.0.0

多直播间 / 多账号大版本。

### 新增

- **多直播间、多账号**：每个任务独立 Cookie、房间、间隔、颜色、位置和内容来源，可同时发送；
  「多直播间」页支持逐个或全部启动 / 停止，并显示运行状态与进度。
- **发送权限检测**：通过 `GetDMConfigByGroup` 获取当前账号在该直播间可用的颜色和模式；
  顶部 / 底部弹幕、彩色弹幕需要舰长 / 房管等身份时，界面只列出可用项，发送时也会自动回退。
- **直播间专属表情**：拉取表情包，按接口 `perm` 标记可用 / 锁定并显示解锁条件；
  图片缓存到本地，点击即可加入弹幕池，发送时使用 `dm_type` + `emoticon_unique` 参数。
- **说书人模式**：选择小说、自动按标点和字数切分成 ≤20 字，按顺序发送；
  每成功发送一段保存进度，下次启动从上次位置继续，支持从头开始。
- **单条弹幕**：自定义内容立即发送，不影响弹幕池和说书进度。
- **配置自动迁移**：旧版单直播间 `config.json` 会转换为一个任务，无需手动改配置。
- 消息库支持表情条目，日志和状态按任务区分。

### 调整

- 界面重写为：发送 / 多直播间 / 表情 / 说书人 / 消息库 / 运行日志 六个页签。
- 发送线程按任务拆分，每个任务独立运行、独立停止。
- Cookie 仍默认打码，可一键关闭保存；日志不写 Cookie，也不写完整 UID。

### 说明

- 顶部 / 底部弹幕和彩色弹幕的身份门槛由 B 站接口返回，程序会自动适配，但无法绕过。
- 表情发送参数按 B 站网页播放器请求构造；若某个表情发送失败，日志会给出返回码便于排查。
- 内置 Python 3.11.9 + tkinter，解压后双击 `run.bat` 即可。
