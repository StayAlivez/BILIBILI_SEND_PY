## BILIBILI_SEND_PY v1.1.2

修复：关闭「显示 Cookie」时无法输入 Cookie 的问题。

### 变更

- 打码状态改用密码框：仍可以直接输入、粘贴、清空，只是内容显示为圆点
- 勾选「显示 Cookie」时切换为多行文本框，方便查看和编辑很长的 Cookie
- 其余隐私行为不变：可关闭保存、日志不写 UID、状态栏只提示「Cookie 可用（已打码）」
- 免安装包仍内置 Python 3.11.9 + tkinter

### 使用

下载 `BILIBILI_SEND_PY_v1.1.2_portable_win64.zip`，解压后双击 `run.bat`；
如果没反应，双击 `debug.bat` 可以看到具体报错。
