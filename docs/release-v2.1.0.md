## BILIBILI_SEND_PY v2.1.0

这次主要修复表情弹幕发送，并补齐直播间实时互动能力。

### 修复

- **表情弹幕发送失败（code=10203）**：按 B 站网页端实际表单修正参数：
  - 不可拼文字的表情：`msg` 使用 `emoticon_unique`，并带 `dm_type=1`、`emoticonOptions`、`data_extend`、`web_location`
  - 可拼文字的表情：按 `[触发词] + 文字` 作为普通弹幕发送，不再带表情字段
- 已用真实账号实测：`teto` 单表情、`[妙] 测试` 拼接文字均返回 `code=0 发送成功`
- 按 `pkg_type` 自动判断能否拼文字：不可拼的表情会禁用文字输入，避免组合后失败
- 表情缓存补充 `pkg_type/combinable`，旧缓存自动重新拉取

### 新增

- **复读机模式**：每个发送间隔统计直播间弹幕，自动复读窗口内出现次数最多的一条；
  排除自己的弹幕和表情弹幕，没有合适内容时跳过本轮。
- **直播间弹幕实时滚动**：打开页签自动开始，默认每 2 秒刷新，可在 1–60 秒之间调整；
  新弹幕自动追加并滚动到底部，可关闭自动滚动。
- **复读 / +1**：双击弹幕或选中后点「复读选中」即可原样复读。
- **表情缩略图**：单条弹幕、消息编辑器选中表情时显示缩略图，运行日志的表情发送记录也带缩略图。

### 调整

- README 精简为一页，保留下载、快速开始、功能、开发和注意事项。
- 直播间弹幕、复读机均使用当前任务的独立 Cookie 与房间。

### 说明

- 顶部 / 底部、彩色弹幕仍受账号身份限制，程序只检测并自动回退。
- 复读机、实时弹幕都需要当前任务的 Cookie。
- 内置 Python 3.11.9 + tkinter，解压后双击 `run.bat` 即可。
