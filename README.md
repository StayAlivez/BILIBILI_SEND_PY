# BILIBILI_SEND · 直播弹幕助手

用 Python + Tkinter 写的 B 站直播弹幕工具：多直播间 / 多账号、发送权限检测、专属表情、说书人、单条发送。

## 下载

**https://github.com/StayAlivez/BILIBILI_SEND_PY/releases**

- 免安装包内置 Python 3.11.9 + tkinter，解压后双击 `run.bat`，无需安装 Python
- 打不开就双击 `debug.bat` 看报错
- 仅支持 Windows 10 / 11 64 位

## 快速开始

1. 双击 `run.bat`。
2. 在「发送」页填房间号，点「检测直播间 / 权限」。
3. 粘贴 Cookie（需要 `SESSDATA` 和 `bili_jct`）。
4. 选择内容来源：弹幕池 / 说书人。
5. 点「开始发送」。

多直播间：在「多直播间」页「新增任务」，每个任务独立 Cookie，可单独或全部启动。

## 功能

- **多任务**：每个任务独立 Cookie、房间、间隔、颜色、位置和来源，多账号 / 多直播间同时发送。
- **权限检测**：发送前读取账号在该直播间可用的颜色和模式；顶部 / 底部 / 彩色需要舰长或房管，界面只显示可用项，发送时自动回退。
- **专属表情**：按直播间拉取表情，标记可用 / 锁定并缓存图片；可加入弹幕池、单独发送，或保存整个表情包到本地。
- **说书人**：读取 `.txt` 小说，自动切成 ≤20 字，按顺序发送，进度自动保存，下次继续。
- **单条弹幕**：自定义内容或选择表情立即发送，支持表情 + 文字。
- **消息库**：权重随机 / 完全随机、避免连续重复，可直接发送选中的文字或表情。
- **隐私**：Cookie 默认打码，可关闭保存；日志不写 Cookie 和完整 UID。

## 目录

```

├── main.py              # 入口：GUI，--cli 命令行
├── run.bat / debug.bat  # 启动
├── config.json          # 配置（自动生成，含 Cookie，不提交）

├── tools/               # 打包 / 发布脚本
```

## 注意

- 顶部 / 底部弹幕和彩色弹幕需要舰长 / 房管身份，程序只做检测和回退，不能绕过。
- 发送太快会被限流（`10031` / `-509`），建议间隔 ≥ 10 秒。
- 多账号同时发送时请自行控制频率，账号风险自负；仅供个人学习。
- 表情发送参数按 B 站网页播放器构造，若个别表情失败，日志会给出返回码。
